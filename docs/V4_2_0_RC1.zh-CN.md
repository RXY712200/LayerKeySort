## 本地验证

使用 Windows GCC 16.2.0 和 Ninja。Debug 和 Release 均通过 `-DLKS_BUILD_BENCHMARKS=ON` 与 `-DCMAKE_C_FLAGS="-Wall -Wextra -Wpedantic -Werror"` 配置、构建并运行 CTest，结果各为 39/39。七个 Release 程序均运行。以下命令均通过：

```text
python tools/verify_v4_api.py
python tools/validate_distribution.py --generator Ninja --c-compiler gcc --cxx-compiler g++
python tools/package_release.py --output-dir build/rc-assets
python tools/validate_release_assets.py --asset-dir build/rc-assets
```

执行了源码、安装及合并版 C/C++ 消费者。候选 ZIP 的 SHA-256 为 `a4a1596b6caa5a7f51895c9fcd1c5e2f6a628298143f517038aec3ac2a942b8d`。重复生成一致，验证拒绝破坏校验和的包。资产仍在本地。
