# LayerKeySort v4.2.0——拟发布说明

[English](V4_2_0_RELEASE_NOTES.md)

仅为准备。计划发行名：**LayerKeySort v4.2.0**；计划注解标签：`v4.2.0`，指向另行批准的最终集成 SHA。计划 GitHub 标志：draft=false、prerelease=false、Latest=true。此处不指定发布日期，也未实际发布。

Full v4.2.0 是兼容的 C17 更新，面向动态顺序、稳定指针数组排序、不可变有序批次及历史快照。保留 64 函数／14 类型源码 API、LS1 和 LKS4SNP1、稳定实例 Handle 及调用者拥有的载荷。

## 改进

- 普通修改只更新受影响的记录位置。
- 跨块先后使用有界标签，无标签时按高度／父指针进行 AVL 回退；局部结构工作仍由块策略及平衡索引维护约束。
- 快照线格式采用可移植固定宽度转换，保持精确字节和先验证后分配。
- 偏移一字节线格式和恢复后混合标签回归增强保留实现的覆盖。
- 完整双语使用及实现指南说明实际工作流、共享对象修改、并发、失败恢复、分发及兼容。

## 证据

未变运行实现的 Windows/Linux 配对归档测得 Full/4.1 总体耗时比中位数为 0.629106/0.640047，比较密集为 0.197718/0.219173；每平台胜出 45/45。这些结论适用于具体对照与负载。原生标签区间 OM 在若干更新密集条件胜出；端点平面历史组合在对应生命周期比较更快，Treap 批量恢复未测。没有新的 Stable 基准。见[完整证据](FULL_RC1_EVIDENCE.zh-CN.md)。

验证包含严格 C17、API／线格式向量、故障注入、七个示例和 C/C++ 源码／安装／合并版消费者。最终确切 HEAD 平台结果由准备交付记录提供；发布前须从最终集成目标重建并验证资产。

## 实际边界

逐实例分配、块空余、回调、O(N+A) 历史导出、保留快照及恢复临时数组仍有成本。应用管理身份、事务、回调副作用与同步。不提供普遍速度优势、端到端硬延迟、通用二进制 ABI、数据库或 CRDT。Mini 与 Workbench 不变，下游依赖采用另行决定。
