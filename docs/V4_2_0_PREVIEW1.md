This campaign lacks contemporary OM rows. A parallel isolated OrdWeave build/test may have overlapped initial Windows replay activity. RSS is coarse process-level evidence, and elapsed trace variation is not operation latency.

Build the three pinned Full implementations as Release static libraries using CMake/Ninja. Fetch the immutable archive branch into the local Git object store. From the candidate root run `python -B benchmarks/research/full-v4.2.0-preview.1/final_c_matrix.py <new-output-dir> <stable40-library> <stable41-library> <candidate-library>`.
