# v3.1.0 发布后合成负载证据

[历史英文原文](WORKLOAD_EVIDENCE.md)。Full v4.2.0 见[后续 Preview.3 配对和资源证据](FULL_RC1_EVIDENCE.zh-CN.md)。

当时建议在未来 3.2 研究兼容尾延迟改善。近尾时间线出现罕见但可复现的全区间重标暂停。它属于负载证据，未发现生产正确性缺陷，也未据此改动算法、API、版本、Path/LK1、打包或发布。

- 生产基线 `dfa9562b9471947cfbd4ee1d1750a59434be83e2`（v3.1.0）。模拟器冻结于 `640fe49e50df3aa21f50569b5ea3b2bf1d54a89f`。

- 52 对场景、104 次执行，每种构建测 3,809,377 次插入；初建不计时。生产与诊断的轨迹、检查点坐标摘要一致。
- 主种子 17、305419896、2654435769、826366246、12648430。预留 3512641005（0xD15EA5ED）在主场景和对照之后运行，定义不变。

- 各次检查操作零、十个固定间隔及结束，共 1,144 检查点。默认有界尾输出 2,960 行，无完整原始轨迹。

## 合成场景

| 优先级/任务 | 35% 新建、25% 删除、40% 优先级更新；32 个等值桶 | 稳定重复排序及优先级变更；约每操作增长 0.1 项 |

负载模拟应用形态，与现场用户研究或轨迹不同。局部移动按数值距离，不是确切秩。删除按键选择第一个等值项，不模拟对象 ID 查询。只有删除后才更改参与比较的键。键分布和 PRNG 见方法文档。

## 正确性与测量边界

未观察到正确性失败。平面参考按键及新插入序号独立排序。在检查点核对大小、全部身份及成员、等值稳定性、严格 Path 顺序及 32 项首等值定位和精确 Path 查找。诊断销毁后库中仍在使用的请求字节归零。参考自检拒绝蓄意损坏的稳定顺序和成员；Python 冒烟拒绝不完整或损坏输出及非法 CLI。

计时仅围绕托管插入。重新插入不含先前定位或删除、键生成、参考排序、分析和 Python 调度。诊断是独立进程和插桩耗时。墙钟 `timespec_get(TIME_UTC)` 使用纪元毫秒，double 粒度约 0.244 μs，中央分位常接近分辨率，未隔离噪声及调度。最近秩法；不足 10,000 次插入不报 P99.9。最大值不构成保证。

## 决策：观察、解释、未知

**观察：** timeline 中/大规模罕见但重复的全区间暂停约 85–225 ms。priority 尾较小但不可忽略，local/churn 此次区域较小。长 churn 的 Path/LK1 驻留温和增长，未见清理泄漏或参考偏差。

**解释：** 当时选择 B，调查兼容 3.2 方向；单独研究尾部回填或内部间隙耗尽、失败候选及扩张，验证坐标复用或有界增量重标准备能否在保留 API/LK1 及强失败语义下减轻暂停。priority 桶变化值得独立研究。保持已发布实现并继续复现及收集外部应用轨迹。这些不是已接受变更或发布承诺。后续 Full V4 已另行开发和发布。此次证据未提示 3.1.x 正确性修复，也未独立构成破坏性 V4 依据。应用是否接受同步暂停取决于未由合成场景给出的延迟预算。

**未知：** 真实频率、用户预算、更大更复杂比较器、并发及后台负载、其他设备分配器、确切秩编辑、操作次数远超驻留规模十倍的历史和低于采样截断的尾。五种子一致支持复现，不确立用户代表性或最坏/摊还界。此任务没有调优算法。
