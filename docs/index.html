Getting the code

One library, several ways to use it

For a small C project, download the two-file amalgamation from GitHub Releases. Copy layerkeysort.h and layerkeysort.c into your project and compile the implementation as C17.

Already using CMake? Choose FetchContent, add_subdirectory, or a local install with find_package. The integration guide has complete commands; 中文集成指南 covers the same first-use paths.

LayerKeySort 4.0.0 is the current Stable release. V3.1.0 remains available for legacy Path/Tree contracts. The V4 Release includes the amalgamation ZIP and a SHA-256 checksum manifest.

Which API?

  • LksManagedOrder binds comparator order; remove/edit/reinsert when keys change.
  • LksOrder supports relative insertion and resident-preserving moves.
  • lks_sort() stably sorts a pointer array once.

Before you adopt it

Measure the workload that matters to you

V4 avoids live Path growth and collection-wide coordinate relabel. Local block/index work, allocation and comparator costs remain; full snapshot export and retained history can dominate time and memory. No universal latency guarantee or distributed/CRDT ordering is claimed. Read the benchmark evidence and test your own insertion patterns.
