## [4.1.0] - 2026-10-25

固定三步优化周期产出的兼容 Full 4.x 小版本。无新增或变更的公开函数、类型、状态、线格式或所有权行为；Mini 独立编号。

- **实时顺序：** 每块共享容器 owner 元数据。实测 x64 Resident 由 32 降至 24 字节，块由 584 增至 592 字节；地址、B64/AVL 工作、Handle 寿命、失败原子性及每记录分配频率保持。
- **快照/历史：** 每行保存累计关联结束位置，取代偏移与长度对，实测 x64 由 16 降至 8 字节。头、行和域同次分配，关联容量发布前收缩。最终收缩可能失败，有 OOM 回归。快照仍独立拥有副本，恢复仍先解析。
- **内存：** 1m 居民与 16 个 ID8 快照的 Full 请求峰值由 513.594 MB 降至 355.751 MB。通过资源准入的 Linux 10m/2 快照由 1,822.185 MB 降至 1,317.500 MB。指标为 Full 分配请求量；RSS 另计。
- **已知成本：** Linux 3m 随机查找相对 4.0.0 慢约 10.2%；一个大命名空间格式化轨迹相对 Step 1 慢约 25.1%。部分宽载荷序列化、移动、销毁亦退化。没有通用加速或端到端延迟界。
- **工具：** 修正分发验证器对 Windows 隐式单配置 Debug 的处理。保留可复现合并版及外部 C17/C++ 消费验证。
- **证据：** [独立最终审核与原始数据](https://github.com/RXY712200/LayerKeySort/blob/6325a6b16d2fe049b7bbc1227c017d6bfb5593b8/benchmarks/research/final-step3/REPORT.md)。确切受审核提交通过 Full 回归和跨平台 CI；原 4.0.0 资产及历史研究不变。

参见 [v4.1.0 兼容说明](V4_1_0.zh-CN.md)和[正式发布](https://github.com/RXY712200/LayerKeySort/releases/tag/v4.1.0)。

- 新增托管不变量/OOM 和 Stable V2 直接基准；保留较慢的 100k 升序及全等，无完整插入最坏或摊还界。

## [2.0.0-preview.4] - 2026-09-30

实验快照。

- 用 Path 键平衡索引解耦 Tree 物理拓扑与 Path 层级。独特显式 Path 不再需要物理前缀。
- 移除可变 ChildBlock 及线性等值后继扫描。比较器插入可重标有界逻辑区间；保留失败原子的全重建回退。
- 深 Path 不再导致同等物理深度。物理导航由实现定义；所有权和失败原子性不变。
- 新增不分配、不压缩的 Path 删除及调用者对象坐标失败原子改键。发布 Group 仍不可变；后续比较器操作的兼容由调用者负责。
- 严格规范显示解析和独立版本化 LK1:。字节字典序等于 Path 顺序。检查畸形、溢出及分配失败，深 Path 迭代处理。同 Path 改键保留借用。
- 收敛坐标策略命名，移除冗余修复阈值，新增 v1 键向量、间隙边界、混合 Tree 修改及表示回归。
- 新增可选确定性公开基准，记录 Preview.3/Stage 4/Stage 5 耗时、内存、Path 大小和复杂度。插入采用生成 Path 而不克隆；硬深度内开放端跳过反复无效修复，内部修复和全重建仍可用。报告保留改善及退化。
- 整树序列化和分布式语义为未来可选；坐标持久化不产生永久身份。当时不可用于生产。相对 Preview.3 保留交替及小随机退化。

## [2.0.0-preview.2] - 2026-09-29

### 变更

- Path 过深或缺前缀拓扑时，比较器插入可稀疏重建有界完整局部子树。局部修复太贵时可接受更深 Path，全 Tree 原子重建为最终回退。
- 独立分支准备并验证后无分配拼接；分配失败保留原 Tree。
- 私有诊断统计局部尝试、成功、回退、受影响节点、区间扩张、接受更深 Path 及全重建。

API 和调用者所有权不变；窗口、深度阈值及稀疏槽间距为临时策略。

## [2.0.0-preview.1]

### 新增

- lks_sort 稳定排序调用者指针数组。
- CMake 生产库、示例和诊断测试，跨平台 CI。
- 稀疏 26 路批 Path 构建及针对性 V2 回归。

### 变更

- Group 构建与合并按最终稳定顺序分配新平衡 Path；输入不可变，结果无需复用源坐标。
- Batch 合并先合并有序指针序列，再做一次 Group 构建。
- 在线插入用可用间隙，增长越过临时阈值则原子重建 Tree。
- 生产分配不再更新进程全局测试计数；诊断仍支持注入及详细计数。

Path 分配策略在 v2.0.0 前可变。Path 表示顺序坐标，与持久 ID 或序列化格式不同。
