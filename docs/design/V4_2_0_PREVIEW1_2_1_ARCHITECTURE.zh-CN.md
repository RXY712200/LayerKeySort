## 实际基线与成本模型

主要实现为 Preview.1.2，提交 `61e9290ec5ba47b9092bcb8ae7d61f13104ea839`。稳定句柄独立分配。容量为 64 的块通过前驱／后继链接相连，块内保存指向驻留记录的指针，每条记录保存所属块和块内位置。常规插入和删除会移动受影响的后缀，再更新位置。同块移动仅修复受影响的区间。跨块移动先准备所需的新块，再摘取记录并放到最终位置，最后按移动后的邻接关系修复占用不足的源块。拆分、重新分配和合并可能移动驻留记录指针，并更新其位置与所属块。除仅有一个块的情况外，每块至少半满。批量恢复会创建新句柄，均匀分配块标签，并建立平衡索引。标签不写入 `LS1` 或 `LKS4SNP1`。

AVL 在块接入、摘除和旋转时维护高度与子树块数。托管顺序的搜索依赖索引和比较器回调，标签快速路径则不调用该比较器。跨块比较在两个标签均非零时直接比较标签，否则按高度沿 AVL 父链接回退。此前匹配条件下的公开比较探针在 Windows 上测得 100k 规模耗时 3.891 ns。先前省去子树块计数的对照结果基本持平，本轮因此保留元数据和向上更新过程。省去高度传播须先独立证明结构不变量仍成立。

## 已测瓶颈

确定性的原生轨迹将分配、位置赋值、触及的索引块、结构事件和托管比较次数与前台计时分别记录。计数用于描述工作量，采集时没有硬件缓存计数器。初始 10k 项、执行 5k 次操作时，本地 B64 诊断的长距离移动轨迹记录 276,797 次位置赋值、460 次拆分、225 次合并和 6,038 次索引块触及。端点轨迹记录 44,888 次赋值、467 次拆分和 4,395 次索引块触及。上述计数包括初始构建。托管随机轨迹记录 190,112 次比较器调用和 379,347 次位置赋值。端点和热点插入仍需分配驻留记录，数组复制只占插入成本的一部分。

`index_blocks` 沿用原 AVL 结构计数定义，标签写入另计。结构探针报告标签累计写入与修复次数、单次接入的最大写入次数、块占用率、当前零标签数量、最长的连续零标签区段及实际比较路径。逐操作尾部计时受时钟分辨率、分配器及运行环境影响。多种负载以及重复的热点与长操作回放展示了结构维护和局部性的取舍，只读对照单独测量。

## 筛选设计

| 方向 | 实际筛选与取舍 |
| --- | --- |
| 边界转移 | 用直接复制边界处的驻留记录指针代替两个临时数组；必要时对右块保留项执行一次允许重叠的移动。删除后源块的位置字段可能尚未更新，因此保留全部位置修复。保留 B64 的预热、拆分与合并阈值、AVL 接入与摘除，以及标签策略。 |
| B32 和 B128 | 只改私有的偶数容量。半满下限、临时溢出槽和批建计算由容量推导。B32 缩短需移动的后缀，但会产生更多块和接入操作。B128 减少索引节点，却增加块内移动长度。 |
| 标签恢复 | 保留至多 64 块的重标，测试 100k 集中插入、收缩及两个刻意留作零标签的块被重叠窗口覆盖后的恢复。回退比较跨过多个零标签时仍正确，非零标签子序列严格递增。后续接入若成功修复覆盖这些块的窗口，即可恢复标签；并非每个场景都要恢复全部零标签。 |
| AVL 与句柄表示 | 保留当前索引和独立分配的稳定句柄。先前移除计数的对照及稀疏内存块保留分析均未支持采用新生产变体。本轮没有实测能保证句柄生命周期的内存池，也没有隔离分配器或缓存各自的因果影响。 |

转移原型按左块在前、右块在后的次序拼接。左块目标数量增加时移动右块前缀，减少时把左块后缀移成右块前缀。最终占用与已采用的算法相同。两块的数组独立分配，跨块复制不重叠。修复可在免分配的源块摘取后运行，不引入新的失败点。两种容量变体均用独立核查的驻留序列及既有修改模型验证不变量。原型保留在研究工作区，未引入第三方代码。

## 采用的诊断修改

提交 `c977b0fd14a501d769b9783bfdcc61266bd1b5ae` 中，`v4_check_node` 在 AVL 中序遍历期间记录最近一个非零标签；该遍历同时核对前驱／后继链接反映的顺序。零标签不覆盖记录值，因此即使两个非零标签之间隔着零标签，检查器也能拒绝相等或下降的标签。此改动仅编译进诊断构建，检查器状态增添一个机器字，无需增加每块的存储或额外遍历。回归测试会还原修改过的标签，原有标签耗尽用例继续检查 AVL 回退比较。此次决定没有选用新的生产版本或运行算法。
