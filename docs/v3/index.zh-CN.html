物理索引

两种树使用 Path 键 AVL。物理父子关系由实现定义，不代表 Path 前缀或逻辑父子。托管重标记保留现有物理节点，只替换 Path 坐标。

持久化

规范显示文本表示可读 Path。版本化 LK1: 键可保存一个当前坐标并按字节排序；两者均不保存对象载荷、永久 ID 或整棵树。

需要考虑的限制

托管插入可能重标记整个逻辑范围，造成明显同步尾延迟。Path 深度和存储取决于负载。完整插入没有已证明的最坏 O(log n) 保证或正式摊销界。

调用方对象与比较器上下文必须存活。先删除相关项、修改比较字段、再重插；不能在仍驻留时修改排序键。
