      How the display maps to LayerKeySort

      The production Group builder processes input items in order. Tree lookup binary-searches ordered child lists and descends through predecessor children; it returns located neighbors, not a public linear scan. The animation shows the verified position and Path result, without inventing internal comparison probes.

      The default values are unique. This run does not demonstrate stability; LayerKeySort preserves input order for comparator-equal items.

      This is an explanatory visualization; it does not execute the production C implementation in the browser. Randomized runs do not display exact Path text because no JavaScript Path generator is used.
