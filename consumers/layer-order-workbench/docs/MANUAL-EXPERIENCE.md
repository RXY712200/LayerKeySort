# Manual editor-style experience (future evidence)

Use the [build instructions](../README.md), then run a genuine terminal session:

```sh
layer_order_workbench --source human-terminal --trace /new/path/my-session.trace
```

Choose your own small layer-editing task. Create objects, insert duplicate and NULL
payloads, move adjacent and distant occurrences, traverse/compare, remove/reinsert,
and try a retired ID. Use help for syntax. Quit, then replay the saved trace with
--replay. Keep the original unchanged.

Record platform/toolchain/source commit, task intent, who operated the terminal,
preplanned versus spontaneous commands, errors and usability observations. Remove
private business names before sharing. Do not label automation as human operation,
replays as independent users, or this CLI as an integrated GUI editor.

No human sessions were performed by Phase 2 automation. Issue #7 remains incomplete
until real operators supply actual evidence.

中文：请维护者或真实使用者亲自操作并保存轨迹，记录任务意图、来源与使用不便。
本指南只准备流程，不代表真人会话已经发生；自动脚本和重放不计为人工验收。
