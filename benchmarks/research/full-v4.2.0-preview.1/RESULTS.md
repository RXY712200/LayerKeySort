# Windows ancestor comparison screen

Full source c108acd72b37614f4be271c9747484c2dde5eac4 is identical to released Full v4.1.0 in src, include, cmake and CMakeLists.txt. The detached experimental translation unit in ancestor-order.c.txt replaces only the comparison path. It is outside the production source list.

The existing comparison computes two absolute block ranks. The experimental comparison ascends from the block with lower AVL height. Height strictly increases on each parent edge, so neither walk can pass a common ancestor before the other walk reaches it. When blocks become siblings, the left-child relation determines precedence. If an ascent reaches the other current block directly, the child side determines precedence. Same-block comparison continues to use the resident's local index. No extra per-block or per-resident storage is required. Block labels were measured only as a fixed-state ordinal floor. This does not measure label maintenance or establish a viable label design.

At 100,000 residents the median cross-block probe was 99.441 ns for the public comparison, 39.365 ns for the ancestor prototype and 2.459 ns for the loaded fixed ordinal. Same-block medians were 3.131 and 3.112 ns respectively. The prototype can inline in this screen while the production API is external. The mixed replay instead compiles each implementation separately from the harness and does not use LTO.

The mixed screen used all 45 frozen traces, eight process launches per variant and trace, with repeat zero discarded. The retained C harness checked successful comparisons and final order. Median candidate/control cell ratio was 0.54637 for comparison-heavy and 0.91091 overall. Worst candidate/control median ratio was 1.02697. The observed overall reduction of 8.9% falls short of the task's 15% planning objective. Treat it as a promising comparison change with insufficient integrated evidence. No candidate was selected for production in this delivery. No conclusions about compiler/language attribution, write-path costs, latency tails, or lifecycle performance follow from this screen.
