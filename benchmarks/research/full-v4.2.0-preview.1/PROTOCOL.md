# Preview.1 initial comparison screen

At 1,024 and 100,000 append-built occurrences, replay identical precomputed pairs within the same block or across blocks. Compare the unchanged public API with a same-validation ancestor-walk prototype. Also measure the loaded scalar-label comparison floor on fixed state. The scalar floor excludes label maintenance and cannot qualify for adoption. Alternate kernel order and preserve every batch. Verify signs independently against input ordinals before timing.

Reject an ancestor-walk candidate that fails the independent pair oracle or fails to improve broad comparisons by at least 25% in this preliminary screen. This screen cannot authorize adoption. Any surviving candidate must then meet the pinned task's cross-host matrix, correctness and compatibility gates. Preserve resident and block memory for the ancestor variant. Label maintenance needs its own bounded write and memory budget before it can qualify.
